Lecture 6: HTML Forms

Introduction to HTML Forms

HTML Forms allow web applications to collect user input. They are used for tasks like login, registration, and feedback.

Forms communicate with servers to process or store submitted data.

The <form> Element

The <form> tag is the container for all input elements in a web form.

<form action="/submit" method="post">
  <!-- Form content here -->
</form>
Form Attributes
  • action: The URL to send the form data to.
  • method: The HTTP method (GET or POST) used for submission.
  • GET: Sends data via the URL (for small data).
  • POST: Sends data in the request body (for secure/large data).
Form Structure

Forms contain elements for user interaction such as labels, inputs, and buttons.

<form action="/submit" method="post">
  <label for="name">Name:</label>
  <input type="text" id="name" name="name">
</form>
The <label> Element

Associates text with an input field, improving usability and accessibility.

<form>
  <label for="email">Email:</label>
  <input type="email" id="email" name="email">
</form>
The <input> Element

The most commonly used form element for collecting user data.

  • Text
  • Email
  • Password
  • Checkbox
  • Radio
<input type="text" name="username">
Common Input Types
  • Text: Single-line input
  • Password: Hidden characters
  • Email: Validated email format
<input type="email" name="user_email" required>
Checkbox Input
<form>
  <input type="checkbox" id="subscribe" name="subscribe" value="newsletter">
  <label for="subscribe">Subscribe to Newsletter</label>
</form>
Radio Button Input
<form>
  <input type="radio" id="male" name="gender" value="male">
  <label for="male">Male</label>
  <input type="radio" id="female" name="gender" value="female">
  <label for="female">Female</label>
</form>
<select> and <option> Elements

Create dropdown menus with multiple choices.

<form>
  <select name="country">
    <option value="us">United States</option>
    <option value="uk">United Kingdom</option>
  </select>
</form>
The <textarea> Element

Used for multi-line text input, such as comments or messages.

<form>
  <textarea name="message" rows="4" cols="50">Enter your message here...</textarea>
</form>
The <button> Element

Used to submit a form or trigger JavaScript actions.

<form>
  <button type="submit">Submit</button>
</form>
Form Validation Attributes
  • required: Field must be filled before submission.
  • maxlength: Limits maximum characters allowed.
  • pattern: Validates using a regular expression.
<input type="text" name="username" required maxlength="10">
Placeholder Attribute

Displays a hint of the expected input until the user types.

<input type="text" name="username" placeholder="Enter your username">
The name and value Attributes

name: Identifies the input field for server-side processing.

value: Sets a default or submitted value.

<input type="text" name="username" value="JohnDoe">
Form Submission Process

When the user submits, data (based on name and value) is sent to the server.

<form action="/submit" method="post">
  <input type="text" name="username" value="JohnDoe">
</form>
Enhancing Forms with JavaScript

JavaScript adds dynamic validation and interactivity to forms.

  • Real-time validation
  • Dynamic field updates
  • Interactive feedback before submission
Lesson Learning Outcomes (LLOs)
  • Understand how forms collect and submit user data.
  • Use different input types and form controls effectively.
  • Apply validation attributes to ensure data quality.
  • Enhance forms using JavaScript interactivity.
