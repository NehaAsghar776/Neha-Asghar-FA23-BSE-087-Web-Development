What is HTML?

HTML (HyperText Markup Language) is the standard language used to create webpages. It defines the structure of a webpage using elements and tags.

History of HTML
  • 1989: Tim Berners-Lee invents HTML at CERN
  • 1993: HTML 1.0 released
  • 1995: HTML 2.0 adds forms and tables
  • 1997: HTML 4.0 introduces multimedia support
  • 2014: HTML5 becomes standard with audio, video & semantic tags
Evolution: HTML 1.0 – 4.01 focused on basic structure; HTML5 adds multimedia and semantic elements for modern web apps.
XML (eXtensible Markup Language)

XML is a markup language designed to store and transport data — focusing on structure rather than display.

Key Features
  • Allows custom tags (e.g., <student>)
  • Self-descriptive and human-readable
  • Used in web services, data storage, and configurations
  • Strict syntax — must have root element, proper closing tags, case-sensitive
Example
<bookstore>
  <book>
    <title>Learning XML</title>
    <author>John Doe</author>
  </book>
</bookstore>
XHTML (eXtensible HyperText Markup Language)

XHTML combines the structure of HTML with the syntax rules of XML, ensuring better compatibility across platforms and browsers.

Key Features
  • All tags must be properly nested and closed
  • Tags must be lowercase
  • Documents must be well-formed
Example
<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN"
 "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml">
  <head><title>My XHTML Page</title></head>
  <body>
    <h1>Welcome!</h1>
    <p>This is an XHTML page.</p>
  </body>
</html>
Key Differences between HTML & XHTML
HTML XHTML
Less strict; allows some flexibility Stricter syntax and rules
Tags may remain unclosed (e.g., <img>) All tags must be closed (e.g., <img />)
Case-insensitive tags Lowercase tags required
HTML Elements and Tags

An HTML element consists of a tag, its attributes, and the content inside.

<h1>Heading</h1>
  • Headings: <h1> to <h6>
  • Paragraph: <p>
  • Link: <a>
  • Image: <img>
  • Lists: <ul>, <ol>, <li>
Attributes in HTML

Attributes provide additional information about HTML elements.

<img src="image.jpg" alt="An image">
  • src – image source
  • href – link destination
  • id and class – for styling or scripting
Block vs Inline Elements
Block-Level Elements
  • Start on a new line and take full width
  • Examples: <div>, <p>, <h1>, <ul>, <table>
Inline Elements
  • Do not start on a new line and take only necessary width
  • Examples: <span>, <a>, <img>, <strong>, <em>
HTML Validator

An HTML validator checks if your HTML code follows W3C standards.

  • Ensures cross-browser compatibility
  • Detects errors early
  • Improves SEO and accessibility
Common Tools
  • W3C Markup Validator
  • Nu HTML Checker
How to Use
  1. Visit W3C Validator
  2. Upload your HTML file or paste your code
  3. Review highlighted errors and fix them
Lesson Learning Outcomes (LLOs)

  • Differentiate between HTML and XHTML
  • Use block vs inline elements appropriately
  • Validate HTML for error-free web development
