Lecture 8: CSS Selectors

Introduction to CSS Selectors

CSS Selectors define which HTML elements the styles apply to. They are the foundation of CSS, enabling developers to target elements based on their type, attributes, class, or position in the document structure.

  • Basic Selectors
  • Descendant and Child Selectors
  • Attribute Selectors
  • Pseudo-classes
  • Pseudo-elements
Descendant Selector

The descendant selector targets all elements nested inside another element, including children and grandchildren.

Example (descendantSelector.html)
<ol>
  <li>List item one.</li>
  <li>List item two.</li>
  <ul>
    <li>Sublist item a.</li>
    <li>Sublist item b.</li>
  </ul>
  <li>List item three.</li>
</ol>

ol li {
  color: skyblue;
}

This selector applies color: skyblue to all <li> elements inside an <ol> — whether they are direct or nested descendants.

Child Selector

The child selector targets only the immediate children of an element (not grandchildren).

ol > li {
  color: skyblue;
}

This means only direct <li> elements inside the <ol> will be styled.

Attribute Selector

Attribute selectors target elements based on specific attributes and values.

Example (attributeSelector.html)
<ul>
  <li><a href="https://google.com">Google</a></li>
  <li><a href="https://facebook.com">Facebook</a></li>
  <li><a href="https://amazon.com">Amazon</a></li>
</ul>

a {
  color: skyblue;
}
a[href="https://facebook.com"] {
  color: white;
}

In this example, all links are skyblue by default, but the Facebook link is styled white using the attribute selector.

Pseudo-class Selectors

Pseudo-classes define the special state of an element, such as when it’s hovered, focused, or clicked.

Example (pseudoclassSelector.html)
<button>Click Me!</button>

button {
  background-color: skyblue;
  font-size: 24px;
  width: 200px;
  height: 50px;
}
button:hover {
  background-color: white;
  color: black;
}

In this example, the button turns white with black text when the user hovers the mouse pointer over it.

CSS Pseudo-elements

Pseudo-elements are used to style specific parts of an element, such as the first letter or the first line of text.

p::first-letter {
  font-size: 24px;
  color: skyblue;
}

This makes the first letter of each paragraph large and sky blue.

Summary
  • Descendant Selector: Targets nested elements.
  • Child Selector: Targets only direct child elements.
  • Attribute Selector: Matches elements with specific attributes.
  • Pseudo-class: Styles an element in a particular state.
  • Pseudo-element: Styles a specific part of an element.
Lesson Learning Outcomes (LLOs)
  • Understand and apply descendant, child, and attribute selectors.
  • Use pseudo-classes to style elements in different states.
  • Use pseudo-elements to enhance specific text parts.
