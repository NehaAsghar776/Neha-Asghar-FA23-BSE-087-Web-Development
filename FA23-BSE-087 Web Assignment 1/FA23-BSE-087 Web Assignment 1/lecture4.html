Lecture 4: Tables, Div, Span, and Layout Design in HTML

Introduction to HTML Layout

HTML provides basic elements for structuring web content. In this lecture, we focus on Tables, Div, and Span for layout design.

These elements help organize and structure content within a webpage efficiently.

What Are HTML Tables?

Tables are used to present data in a tabular format consisting of rows and columns. They are primarily meant for data representation, not for layout design (as was common in early web pages).

Basic Table Structure
<table>
  <tr>
    <th>Header 1</th>
    <th>Header 2</th>
  </tr>
  <tr>
    <td>Data 1</td>
    <td>Data 2</td>
  </tr>
</table>
Table Elements
  • <table>: Defines the table structure
  • <tr>: Table row
  • <td>: Table data cell
  • <th>: Table header cell (bold and centered by default)
Using Tables for Layout (Deprecated)

In early web design, tables were often used to structure entire pages.

<table>
  <tr><td>Header</td></tr>
  <tr><td>Content</td></tr>
  <tr><td>Footer</td></tr>
</table>

This approach is discouraged today in favor of flexible layout elements like <div> and <span>.

Table Attributes
  • border: Adds borders around table and cells
  • cellpadding: Adds space inside cells
  • cellspacing: Adds space between cells
<table border="1" cellpadding="5" cellspacing="5"> ... </table>
Colspan vs Rowspan

Cells can span multiple columns or rows for merging data:

<td colspan="2">Merged Column</td>
<td rowspan="2">Merged Row</td>
Introduction to Div

The <div> element is a block-level container used to group and structure content for layout and styling purposes. It is the modern, flexible alternative to using tables for layout.

<div>
  <h1>Title</h1>
  <p>This is a paragraph inside a div.</p>
</div>
Div for Page Sections

A common webpage layout structure using divs:

<div id="header">Header</div>
<div id="content">Main Content</div>
<div id="footer">Footer</div>

This structure helps create logical page divisions that are easier to style and manage.

Introduction to Span

<span> is an inline element used to group text for styling without creating new blocks.

<p>This is a <span>highlighted</span> word in a sentence.</p>
Div vs Span
  • <div>: Block-level, creates a new line, used for sections
  • <span>: Inline, stays in line with text, used for small portions
Layout Design with Tables (Old Method)

Earlier web pages used tables to divide page sections:

<table>
  <tr><td>Header</td></tr>
  <tr><td>Main Content</td></tr>
  <tr><td>Footer</td></tr>
</table>
Div for Layout (Modern Method)
<div id="container">
  <div id="header">Header</div>
  <div id="main-content">Main Content</div>
  <div id="footer">Footer</div>
</div>

Div-based layouts are more flexible and easier to style using CSS.

Nesting Divs

You can nest divs inside each other for complex layouts:

<div class="container">
  <div class="left">Left Section</div>
  <div class="right">Right Section</div>
</div>
Best Practices for Layout
  • Use <div> for block-level sections
  • Use <span> for inline text styling
  • Avoid using tables for layout purposes
  • Use tables only for data presentation
Lesson Learning Outcomes (LLOs)
  • Understand when to use tables, div, and span
  • Recognize that tables are for data, not layout
  • Use divs for page structure and layout
  • Use spans for inline styling
