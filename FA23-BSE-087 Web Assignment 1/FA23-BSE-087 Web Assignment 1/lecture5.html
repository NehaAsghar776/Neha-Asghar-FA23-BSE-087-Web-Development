Lecture 5: Introduction to HTML5

What is HTML5?

HTML5 is the latest version of the HTML standard. It introduces new elements, attributes, and behaviors for modern web development.

It focuses on better semantics, multimedia support, and device independence.

<!DOCTYPE html>
Key Features of HTML5
  • Responsive Design: Automatically adjusts layout for different screen sizes.
  • Viewport Meta Tag: Ensures proper scaling on various devices.
  • Flexible Multimedia: Supports native audio and video playback.
  • Cross-Platform Compatibility: Enables interactive and graphical content (via <canvas>) across devices.
  • Enhanced Forms: New input types like email, tel, date, etc.
  • Offline Support: Uses localStorage and service workers for offline functionality.
HTML5 vs Previous Versions
  • HTML4: Focused on structure using <div> and <span>.
  • HTML5: Introduced semantic tags for meaning and accessibility.
Importance of Semantic HTML

Semantic HTML improves accessibility, SEO, and maintainability of web pages. It helps browsers and search engines understand page structure and content meaning.

Semantic Elements Overview

Semantic elements clearly describe their purpose to both browsers and developers. Examples include:

  • <table>
  • <form>
  • <article>
  • <section>
  • <header>
  • <footer>
Semantic vs Non-Semantic Elements
  • Non-Semantic: <div>, <span> (provide no information about content)
  • Semantic: <form>, <table>, <article>, <nav>, <aside> (define content meaning)
Common Semantic Elements
1. <header> Element
<header>
  <h1>Welcome to My Website</h1>
  <nav>...navigation...</nav>
</header>
2. <footer> Element
<footer>
  <p>&copy; 2024 My Website</p>
</footer>
3. <article> Element
<article>
  <h2>Latest News</h2>
  <p>This is a news article.</p>
</article>
4. <section> Element
<section>
  <h2>About Us</h2>
  <p>Details about the company...</p>
</section>
5. <nav> Element
<nav>
  <ul>
    <li><a href="#home">Home</a></li>
    <li><a href="#about">About</a></li>
  </ul>
</nav>
6. <aside> Element
<aside>
  <p>Related article or content.</p>
</aside>
7. <figure> and <figcaption> Elements
<figure>
  <img src="images/example.jpg" alt="Description">
  <figcaption>Figure 1: An example image.</figcaption>
</figure>
Multimedia in HTML5

HTML5 introduces native support for audio and video without requiring plugins.

<video controls>
  <source src="video.mp4" type="video/mp4">
</video>
The <canvas> Element

The <canvas> element is used for drawing graphics, animations, or games using JavaScript. It supports 2D and 3D rendering (via WebGL).

<canvas id="myCanvas" width="500" height="400"></canvas>
New Input Types in HTML5
  • email
  • url
  • date
  • range
  • number
<input type="email" placeholder="Enter your email">
HTML5 Storage Options
  • localStorage: Stores data permanently (no expiration).
  • sessionStorage: Stores data for the current session.
localStorage.setItem('key', 'value');
Browser Compatibility

HTML5 is widely supported across modern browsers such as Chrome, Firefox, Safari, and Edge. Features like semantic elements, video, audio, and canvas work seamlessly.

Lesson Learning Outcomes (LLOs)
  • Understand the new features introduced in HTML5.
  • Use semantic elements for structure and accessibility.
  • Implement multimedia using native tags.
  • Apply storage APIs for offline functionality.
Final Tip: Always use semantic elements for better SEO and maintainable web pages.
