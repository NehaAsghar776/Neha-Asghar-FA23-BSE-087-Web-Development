Lecture 7: Introduction to CSS

What is CSS?

CSS (Cascading Style Sheets) is the language used to style and format web pages. It describes how HTML elements are displayed on the screen, paper, or other media.

  • CSS controls layout, color, font, and spacing.
  • External stylesheets allow consistent styling across multiple web pages.
  • CSS saves time and improves maintainability.
CSS Syntax

A CSS rule consists of a selector and a declaration block.

h1 {
  color: red;
  text-align: right;
}

The declaration block contains properties and their corresponding values.

p {
  font-family: Arial;
  font-size: 20px;
}
Common CSS Properties
  • color
  • text-align
  • font-family
  • font-size
  • width / height
  • margin / padding
  • border
Ways to Add CSS

There are three main ways to include CSS in your web page:

  • Inline CSS: Inside the HTML element using the style attribute.
  • Internal CSS: Inside a <style> tag within the <head>.
  • External CSS: Using a separate .css file linked with <link>.
Example – Inline CSS
<h1 style="color: brown; text-align: center;">Hello</h1>
<body style="background-color: #1e1e1e;">
Typeface (Font Family)

A typeface is a set of characters with a consistent design. A font is a particular implementation of a typeface (weight, size, and style).

font: bold 40px sans-serif;
Common Font Families
  • Serif: Decorative ends on letters, classic and traditional.
  • Sans-serif: Clean, modern, and easy to read on screens.
  • Monospace: Equal spacing for all letters (used for code).
  • Cursive: Imitates handwriting or brush script.
  • Fantasy: Decorative and playful fonts.
Note: Sans-serif fonts are generally easier to read on digital screens.
Example – External CSS
h1 {
  color: brown;
  text-align: left;
  font-family: Arial, sans-serif;
  font-size: 28px;
  font-weight: normal;
}
CSS Box Model

Every HTML element can be viewed as a box consisting of:

  • Content
  • Padding
  • Border
  • Margin
Table Border Example
table {
  border: 1px solid #a47148;
  border-collapse: collapse;
}
td, th {
  border: 1px solid #a47148;
  padding: 5px;
}
Identifying Elements (div, span, id, class)
<div>Hello, World!</div>

div {
  background-color: #a47148;
  width: 200px;
  height: 200px;
  padding: 20px;
  margin: 20px;
  border: 3px dashed #fff;
}
ID and Class Example
<h1 id="foo">Heading1</h1>
<h1 id="bar">Heading2</h1>
<h1 class="baz">Heading3</h1>
    
#foo { color: #a47148; }
#bar { color: #d9a066; }
.baz { color: #c58b59; }
CSS Specificity (Precedence)

When multiple CSS rules apply to the same element, the one with higher specificity takes precedence.

  • Inline styles (highest)
  • ID selectors
  • Class selectors
  • Type selectors (lowest)
Lesson Learning Outcomes (LLOs)
  • Understand CSS structure and syntax.
  • Use inline, internal, and external CSS.
  • Distinguish between typeface and font.
  • Explain the CSS box model.
  • Understand CSS specificity and precedence.
