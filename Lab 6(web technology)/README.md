# Web Technology Lab 6 Activities

This repository contains five HTML files, each demonstrating a different web technology concept.

## Activity 1: Number Field

**File:** `activity1.html`

This activity demonstrates how to access the value of a number input field using JavaScript.

## Activity 2: Search Field

**File:** `activity2.html`

This activity demonstrates a simple search field. When the user enters text and clicks the button, the entered text is displayed.

## Activity 3: JavaScript Numbers

**File:** `activity3.html`

This activity demonstrates the use of scientific (exponent) notation for representing very large or very small numbers in JavaScript.

## Activity 4: Today's Date

**File:** `activity4.html`

This activity shows how to get and display the current date and time using the JavaScript `Date` object.

## Activity 5: Number Guessing Game

**File:** `activity5.html`

This is a simple number guessing game. The user is prompted to enter a number between 0 and 9, and the script checks if it matches a randomly generated number.
